# ASTR-5470-Final-Project
## N-body Tidal Disruption Model of Dwarf Galaxies

Download and install this branch

```git clone https://github.com/katzberger4/ASTR-5470-Final-Project.git```

In nbody_sim/examples:

- Produce a snapshot of the final stellar stream

  ```python run_stream_simulation.py```

- Check energy conservation

  ```python check_energy_conservation.py```

- Evolve angular momentum

  ```python evolve_angular_momentum.py```

- Plot the particle orbits and radial profile evolution

  ```python orbits_and_radial_profile.py```
